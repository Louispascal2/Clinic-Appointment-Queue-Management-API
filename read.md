# Clinic Appointment & Queue Management API is a role-based access control which has its users as patient, receptionist, doctor, and admin. Each has a role to play.


# Tech Stack 
 - Node.js / Express
 - MongoDB/ Mongoose
 

# Auth & Security
- JWT(jsonwebtoken)
- bcrypt(password hashing)
- cookie-parser (cookie handling)


# Dev tools
- Nodemon
